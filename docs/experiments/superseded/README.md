# Superseded routing-outcome evidence

These artifacts are retained only to preserve the audit trail for the 13 August
2026 analysis. They are not current evidence and must not be quoted in reports,
briefs, or routing recommendations.

They predate the following corrections:

- the treatment was changed from a decoded role-chain feature to the jointly
  selected department and complete intended chain;
- train-fitted encoders and like-for-like policy arms replaced the earlier fit;
- the 2025 temporal OPE check showed that the positive 2024 augmented contrast
  did not replicate;
- the robustness ladder was rerun from the current code with output provenance,
  schema, action definition, and a meaningful seed check; and
- the assignment fields were explicitly classified as unresolved provenance:
  the complaints snapshot may contain later state, while action history records
  realised handling but no department-and-chain assignment snapshots.
